# Raven Step — телепортація шадар-кая

Версія 1.1.0. Ціль: Foundry VTT 14.368 + D&D5e 6.0.6, як у наданому експорті здібності. Потрібен доступ GM до папки даних сервера. Інші модулі, Sequencer, JB2A та платні ресурси не потрібні.

## Встановлення — один раз
1. Розпакуй архів. Скопіюй папку `raven-step` у `Data/modules/` у **User Data Path** Foundry. Результат: `Data/modules/raven-step/module.json`. Не допускай подвійної папки `raven-step/raven-step`.
2. Перезапусти сервер Foundry. Відкрий світ → Game Settings → Manage Modules → увімкни **Raven Step — Shadar-Kai & Misty Step** → Save Module Settings.
3. Переконайся, що **Blessing of the Raven Queen** вже є на листі персонажа. Наданий предмет не треба замінювати: модуль впізнає його за `system.identifier`, навіть якщо перейменувати назву українською.
4. У сцени мають бути коректні одиниці `ft` (зазвичай 5 на клітинку) або `m`. Гравцю потрібні права Owner на персонажа й токен. Увімкни зір токена та налаштуй світло.
5. Усі учасники перезавантажують сторінку. Модуль активується для всіх у світі.

На хостингу без доступу до Data/modules адміністратор має завантажити папку засобами хостингу. ZIP не є Manifest URL; публічне посилання для автоматичного інсталятора не створено.

## Оновлення на Molten Hosting з 1.0.0
1. Розпакуй новий архів на комп’ютері.
2. Відкрий файловий менеджер Molten → Data/modules/raven-step.
3. Завантаж вміст нової папки raven-step поверх старих файлів із заміною. Не створюй вкладену raven-step/raven-step.
4. Перезапусти сервер Molten, потім перезавантаж сторінки гравців. Якщо модуль уже увімкнений, повторна активація не потрібна. Версія у списку модулів: 1.1.0.

## Misty Step
Працює для предмета типу Spell з identifier `misty-step`, або з точною англійською назвою `Misty Step`. Перекладена назва працює за identifier. Наявне закляття не треба замінювати.

Вибери токен → використай Misty Step на листі → вибери точку → підтвердь штатний діалог чарування, якщо він з’явиться. Вибір комірки, Pact Magic і безкоштовні використання делегуються системі D&D5e відповідно до налаштувань цього закляття. Модуль не створює безкоштовних використань сам.

Esc на етапі вибору точки або скасування штатного діалогу не телепортує і не витрачає ресурс. Якщо переміщення заблоковано після успішного чарування, модуль викликає штатне повернення фактично списаних ресурсів. Картка чарування в чаті може залишитися; не повертай ресурс повторно вручну, якщо модуль уже повернув його.

Misty Step використовує ті самі тіньові частинки та звук. Опір шкоді від Raven Queen **не надається**. Окремий необов’язковий Script Macro: `macro-misty-step.js`. Якщо у закляття кілька активностей, запускай потрібну безпосередньо з листа.

## Як користуватися
1. Вибери токен персонажа.
2. На листі натисни **використати** Blessing of the Raven Queen (не просто показати опис). Також працює штатна кнопка використання здібності з панелі швидкого доступу.
3. Переміщуй курсор: фіолетова рамка — допустима точка, червона — помилка з поясненням.
4. ЛКМ підтверджує. Тіньова хмара, фіолетове кільце й частинки-пір'їни супроводжують зникнення та появу; в обох точках звучить короткий низький шумовий свист. Токен справді переміщується.
5. Esc або ПКМ скасовує без витрат. Через 2 хвилини незавершений вибір закривається автоматично.

Налаштування → Configure Settings → Raven Step: власна гучність, вимкнення анімації; GM може вимкнути перехоплення здібності. Власні налаштування звуку застосовуються окремо в кожного гравця.

## Що автоматизовано
- Підключення до наявного предмета без редагування JSON, Item Macro або налаштування кожного персонажа.
- Дальність 30 футів (9.144 м) за правилами вимірювання сітки сцени; прив'язка позиції до сітки.
- Перевірка меж сцени, прямої видимості крізь стіни, доступної видимості для гравця та перетину з токенами на тій самій висоті.
- Одне списання `system.uses.spent`; звичайне відновлення на довгому відпочинку залишається в D&D5e. Скасування й відхилена точка нічого не витрачають. Якщо переміщення заблоковане, модуль намагається повернути використання, не перезаписуючи паралельні зміни ресурсу.
- Повідомлення в чаті та передавання косметичних ефектів учасникам на цій сцені. Прихований токен не показує ефекти звичайним гравцям.

## Межі автоматизації
- **Опір усій шкоді від 3 рівня застосовує та знімає GM вручну до початку наступного ходу.** Модуль нагадує про це в чаті, але не змінює опори персонажа й не створює постійної прозорості.
- Бонусну дію враховуєш вручну; модуль не веде лічильник економіки дій.
- Для Blessing of the Raven Queen перехоплення замінює стандартний workflow саме цієї здібності. Додаткові activity effects, Midi-QOL, автоматичні анімації та зовнішні item macros для неї не виконуються цим модулем. Для Misty Step штатний workflow виконується після вибору точки. В обох випадках вимкни дублюючу телепортацію в інших модулях; сумісність із Midi-QOL не перевірена.
- Одна сцена, поточна висота. Міжсценові переходи, зміна поверху й 3D-колізії не реалізовані. Перевірка зайнятості використовує прямокутники токенів, тож для великих/шестикутних токенів може бути консервативною.
- Перевірка освітлення використовує видимість клієнта Foundry (може включати спільний зір); пряма видимість перевіряється окремо від токена. Особливі чуття, магічна темрява, засліплення, декорації без стін та інші нестандартні випадки перевіряє GM. GM обходить перевірку освітлення, але не дальності/стін/зайнятості.
- Не активуйте здібність одного персонажа одночасно з двох комп'ютерів: міжклієнтного блокування ресурсів немає. Локальні подвійні натискання блокуються.

## Швидка перевірка після встановлення
На тестовій сцені з копією персонажа:
- Використай здібність у межах 30 ft: токен переноситься, витрачено рівно 1 заряд, інший підключений гравець бачить/чує ефект.
- Скасуй через Esc: позиція й заряди не змінилися.
- Повтори перевірку з Misty Step: звичайна комірка, Pact Magic (якщо є), налаштоване безкоштовне використання, скасування діалогу та відсутність комірок.
- Спробуй точку за 30 ft, за непрозорою стіною та на іншому токені: підтвердження не проходить.
- Перевір останній заряд і довгий відпочинок.
- Вимкни модуль: звичайний workflow здібності відновлюється, предмети не потребують ремонту.

## Якщо кнопка не працює
Перевір активність модуля, версію системи, права Owner й вибір токена. Якщо предмет створений вручну, використай Script Macro з файлу `macro.js`: він шукає предмет за identifier або англійською назвою. Не додавай другий екземпляр здібності. Повідомлення про помилку відображається на екрані, подробиці — F12 → Console → `raven-step`.

## Перевірка та джерела
Перевірено синтаксис JavaScript і локальні тести геометрії, скасування, списання та повернення ресурсу з імітацією API; для Misty Step додано тести штатного чарування, скасування діалогу, відсутності комірок, безкоштовного чарування, повернення ресурсу та повторної перевірки точки перед списанням. Повноцінний запуск у Foundry та багатокористувацьке відтворення в цьому середовищі недоступні; сумісність із конкретним набором модулів потребує наведеного тесту в світі.

API: https://github.com/foundryvtt/dnd5e/wiki/Hooks
https://foundryvtt.com/api/classes/foundry.documents.TokenDocument.html
https://foundryvtt.com/api/v14/classes/foundry.canvas.placeables.Token.html
Використовується підтримуваний у v14 compatibility shim `teleport: true` для TokenDocument.update.

Звук синтезований для цього пакета; сторонніх медіа немає. Код і звук можна змінювати та використовувати у своїх світах.
